# 会话流程约束

- 一次练习 = 热身关 + 轮换玩法小关（按 10/15/20 分钟档为 3/4/6 关），打完全部小关即完成。
- 完成一半以上小关（向上取整）才增加 `completedSessions`；不足记为热身，写入 `history` 但不推进课程。
- 提前结束（"结束本次任务"或退出回首页）按同样规则结算，已练内容写入历史。
- 结果页"再飞一次"重练原课次，不重复累计正式进度。
- "继续下一站"使用保存后的正式进度生成下一课次。
- 每完成 2 个小关插入 30 秒可跳过的休息，休息与暂停期间计时（`elapsedSeconds`）不走。
- 未完成练习只存入 `sessionStorage`（draft v2，含小关状态），不会写入正式历史。
- 草稿正常完成、明确放弃或超过 6 小时后清除。
- 有输入或练习超过 10 秒时，退出前必须确认。
- 计时为正计时；到达 60 分钟上限时强制结算，防止无限会话。
