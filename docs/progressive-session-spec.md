# Spec: 渐进式三关课程与五玩法闭环

## Objective

把现有“任意一次输入即可推进课程”的练习循环改为适合 6-8 岁儿童的渐进式闯关：每课次必须依次完成热身关、探险关和冲刺关，且在一次正式闯关中经历五种玩法。提前结束、零输入超时或未达最终条件均不得推进 84 课次进度。

一次课次使用累计目标，并受本机家长设置的 5 / 10 / 15 分钟最长时长约束（默认 5 分钟）：

| 关卡 | 正确键 | 小站 | 准确率 |
| --- | ---: | ---: | --- |
| 热身关 | 12 | 2 | 80% |
| 探险关 | 36 | 6 | 当前难度目标减 6 个百分点，最低 80% |
| 冲刺关 | 60 | 10 | 当前难度目标：86% / 92% / 96% |

每两个小站切换玩法，顺序为找星星、气球防线、小火车、密码门、火箭冲刺。气球防线每个小站需击中 8 颗，漏球只计错误、不推进小站。提示从易到难逐关减少，连续错误达到难度阈值后恢复目标键提示。

## Tech Stack

- Vite 7 + 原生 ES Modules。
- Node.js 内置测试运行器负责纯逻辑测试。
- Playwright 负责关键浏览器流程。
- localStorage / sessionStorage 保存正式进度与未完成草稿。
- 首页本机家长设置保存 5 / 10 / 15 分钟单局上限，不引入远程后台。
- Web Audio / SpeechSynthesis 提供离线声音反馈。
- 不新增运行时框架、远程服务、字体、图片或音频依赖。

## Project Structure

- `src/engine.js`: 课程、物理键位、提示选择和正式课次写入。
- `src/session.js`: 三关要求、准确率、提示策略和完成判定。
- `src/balloon-game.js`: 气球实体、命中和漏球事件。
- `src/main.js`: 浏览器状态编排与输入循环。
- `src/ui.js` / `src/styles.css`: 三关、五玩法、屏幕键盘与结果页。
- `test/`: 纯逻辑与渲染单元测试。
- `e2e/`: 正式闯关、提前结束、难度和键盘课程浏览器测试。

## Code Style

使用纯函数承载规则，浏览器编排只消费规则结果：

```js
export function getSessionProgress(run, difficulty) {
  const accuracy = run.total === 0 ? 0 : run.correct / run.total;
  return { accuracy, completedGates: 0, complete: false };
}
```

- 常量使用大写蛇形命名，函数和状态字段使用小驼峰。
- 外部或存储数据先归一化；渲染动态文本必须转义。
- 活动规则集中定义，不在主循环散落相同条件分支。

## Testing Strategy

- 先写失败测试，再实现课程解锁、三关判定、难度提示和漏球记错。
- 单元测试覆盖物理键位映射、各关边界、未完成不推进和五玩法轮换。
- E2E 覆盖：一次输入不能推进；完成三关后推进一次；重练不重复推进；G/H 与标点键可见；火箭难度按关卡隐藏提示。
- 浏览器人工检查桌面、320px、768px、1024px、1440px，控制台必须无错误或警告。

## Boundaries

- Always: 保持离线优先、无账号、输入不上报；保存已产生的按键熟练度；正式进度只由三关完成触发。
- Ask first: 新增外部服务、账号、云同步、遥测或运行时依赖。
- Never: 用自动解锁掩盖课程数据错误；让提前结束或零输入推进课程；依赖颜色作为唯一状态提示。

## Success Criteria

- 任意一次输入后提前结束，`completedSessions` 不变。
- 未完成三关时达到所选 5 / 10 / 15 分钟上限不推进课程；完成三关可提前结算且只推进一次。
- 三档难度的最终准确率目标分别为 86%、92%、96%，且提示策略实际生效。
- 一次正式闯关包含 10 小站，并按 2 小站轮换完五种玩法。
- 气球漏掉会增加练习错误与对应键弱项统计。
- 气球防线第 1–7 次命中不推进小站，第 8 次命中才推进并清零本小站计数。
- 屏幕键盘包含 G/H、逗号、句号、`/ ?`、`1 !`，Shift 组合被正确教学和统计。
- A、Z、Shift 等键不会早于课程声明解锁，课程数据不一致会让测试失败。
- 单元测试、E2E、构建和依赖审计全部通过，真实浏览器无控制台错误。
