# 会话流程约束

- 一次练习 = 热身关 + 轮换玩法小关（按 10/15/20 分钟档为 3/4/6 关），打完全部小关即完成。
- 完成一半以上小关（向上取整）才增加 `completedSessions`；不足记为热身，写入 `history` 但不推进课程。
- 提前结束（"结束本次任务"或退出回首页）按同样规则结算，已练内容写入历史。
- 结果页"再飞一次"重练原课次，不重复累计正式进度。
- "继续下一站"使用保存后的正式进度生成下一课次。
- 每完成 2 个小关插入 30 秒可跳过的休息，休息与暂停期间计时（`elapsedSeconds`）不走。
- 每位探险家的数据独立存储：花名册在 `typing-adventure:profiles`，档案在 `typing-adventure:profile:<id>`，草稿在 `typing-adventure:draft:<id>`。
- 旧版单档案键 `typing-adventure:profile` 在首次启动时自动迁移为第一位探险家。
- 未完成练习的草稿存入 `localStorage`（draft v2，含小关状态），关闭浏览器后仍可从首页"继续上次探险"恢复；恢复入口是页面卡片，不再用 `window.confirm`。
- 练习中每次落盘（每次按键/每秒）同时保存草稿和档案，中断不丢失按键统计；正式历史仍只在结算时写入。
- 草稿正常完成、开始新练习或超过 24 小时后清除。
- 有输入或练习超过 10 秒时，退出前必须确认。
- 计时为正计时；到达 60 分钟上限时强制结算，防止无限会话。
